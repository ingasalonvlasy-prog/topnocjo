## 4. Nalezené issues

### MINOR — Seed hash funkce je slabá

```ts
const ha = ((a.id.charCodeAt(0) * 31 + daySeed) % 1000) / 1000;
```

Používá pouze **první znak** ID (`charCodeAt(0)`). Pokud mnoho produktů sdílí stejný první znak ID (cuid začíná na `c`), hash bude stejný → sort bude nestabilní/neefektivní. Variabilita shufflu závisí primárně na `daySeed`, ne na ID.

**Dopad:** Nízký — bestsellery se budou měnit denně, ale nemusí být rovnoměrně rozmístěné napříč poolem 60 produktů. Nefunkční bug — vizuální pouze.

**Oprava (doporučení):** Použít více znaků ID nebo celý string hash:
```ts
const ha = (Array.from(a.id).reduce((acc, c) => acc * 31 + c.charCodeAt(0), daySeed) % 1000) / 1000;
```
