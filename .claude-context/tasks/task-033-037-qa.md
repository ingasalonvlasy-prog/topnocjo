**Nalezené problémy:**

**MINOR — N+1 query pro avgOrderValue:**
```ts
// Mimo hlavní Promise.all — extra DB round-trip
const avgOrderValueResult = await prisma.order.count(...);
```
`avgOrderValue` používá extra `prisma.order.count()` volaný mimo `Promise.all`. Funkčně správně, ale zbytečný sériový DB call. Nízká priorita — analytika není hot path.
